# SWYNEX Technologies – Interactive Dashboard

## Task 3: Interactive Dashboard

This project was completed as part of my **Data Analytics Internship at SWYNEX Technologies**.

The objective of this task was to create an interactive dashboard using **Microsoft Power BI** to analyze the Titanic dataset and present important insights through KPIs, charts, and interactive filters.

## Dataset

The dataset used for this project is the cleaned Titanic dataset prepared during Task 1 and used for Exploratory Data Analysis in Task 2.

## Tool Used

- Microsoft Power BI

## Dashboard KPIs

The dashboard includes the following key performance indicators:

- Total Passengers: 891
- Total Survivors: 342
- Survival Rate: 38.38%
- Average Age: 29.39
- Average Fare: 32.20

## Visualizations

The dashboard contains:

1. Survival Rate by Gender
2. Survival Rate by Passenger Class
3. Passengers by Embarked Port
4. Passengers by Age Group
5. Average Fare by Passenger Class

## Interactive Filters

The dashboard includes slicers for:

- Gender
- Passenger Class
- Embarked Port
- Age Group

These filters allow users to interact with the dashboard and explore the data from different perspectives.

## Key Finding

Female passengers had a higher survival rate than male passengers in the Titanic dataset.
